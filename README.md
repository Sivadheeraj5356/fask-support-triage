# Fask Support Triage

A client-side support triage tool for Fask-style AI customer portal workflows. Paste inbound customer messages and the tool classifies each message by intent, urgency, owning team, next action, and evidence. It runs entirely in the browser and stores no customer data.

## Run

Open `index.html` in a browser. No server, dependency, or API key is required.

## Test

```bash
node test.js
```
